## GAP-05 candidate truth

Owner-approved replenishment A8 authorizes the current GAP-05 candidate only. The candidate adds the first human-facing layer with the smallest native path:

```text
mobile/browser
  -> native Hermes Web Dashboard
  -> native Nous Portal OAuth gate
  -> bundled Agent host-policy plugin
  -> Hermes managed scope from GitHub
  -> protected FreeLLMAPI
  -> configured free-provider pool
```

Security/capability facts:

- no dashboard fork, reverse proxy, second auth server or second agent runtime;
- dashboard starts through native `hermes dashboard`, preserving upstream auth/plugin bootstrap;
- `agent-host-policy` is installed through Hermes' supported bundled-plugin directory, so it remains available across Hermes profiles;
- one Modal dashboard container and one dedicated dashboard-state Volume;
- interactive state is stored only in that Hermes Volume; Control/project business truth does not use it;
- provider/model are managed `freellmapi` + `auto` and both Hermes fallback lists are empty;
- `llm_execution` short-circuits any provider/model/base-URL route outside the protected FreeLLMAPI path before downstream provider I/O;
- managed toolsets are `web`, `memory`, `session_search`; native `pre_tool_call` allows only the four exact resolved tools and blocks every other tool fail-closed;
- only `agent-host-policy` is enabled as a general plugin by managed config;
- direct-provider credential names come from the exact pinned Hermes provider catalog and are materialized empty in managed scope; startup rejects any such credential already present;
- non-read browser HTTP methods are default-deny except native auth/session lifecycle and chat-image upload;
- `/api/console` is denied;
- `/api/pty` requires a native keep-alive attach token, closing Hermes' legacy unregistered PTY path;
- native PTY registry maximum is exactly one;
- managed chat PTY inherits `HERMES_GATEWAY_SESSION=1`, disabling exact-pinned Hermes `!command` local-shell mode;
- no target-project production credential enters Hermes.
